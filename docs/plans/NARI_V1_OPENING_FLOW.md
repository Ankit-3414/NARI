# NARI v1 Opening Flow and Animation Spec

## Objective
When the user opens NARI, the experience should feel like entering the Bridge of an intelligence that is already awake.

## Opening Sequence

### 1. Black Screen
The app opens to a dark, minimal screen.
- no clutter
- no dashboard wall
- no instant overload

### 2. NARI Mark Appears
A subtle NARI mark or wordmark fades in.
- soft pulse
- controlled glow
- short duration

### 3. Greeting
NARI greets the user with one concise line.
Example:
> Good afternoon, Ankit.

### 4. Awareness Summary
NARI surfaces a short summary:
- what it notices
- what changed
- what needs attention
- what context matters now

Example:
> I noticed you returned to NARI after a pause.
> Memory Versioning still appears to be the next best step.

### 5. Globe Emerges
The globe fades or grows into view.
- slow rotation
- subtle particles
- ambient motion
- location and weather layering

### 6. Chat Appears
The chat input enters after the awareness summary.
- typed chat only for v1
- voice reserved for v1.5+
- prompt should feel conversational, not transactional

### 7. Main Bridge Becomes Ready
The Bridge is now interactive:
- menu can be opened
- globe can be expanded
- chat can be used
- secondary details stay hidden until requested

## Globe Click / Expand Animation
When the user clicks the globe:
- the globe expands smoothly
- the camera zoom feels continuous
- the UI transitions inside the same page
- the World view takes over the screen
- the globe becomes the context center

The expanded view should reveal:
- live location
- temperature
- weather
- geofence context
- nearby awareness

This should feel like unfolding a layer, not opening a separate app.

## Menu Behavior
The sidebar menu should:
- open on click
- slide in cleanly
- hide automatically after a selection
- disappear when clicking outside
- avoid permanent clutter

## Motion Rules
Use motion only when it communicates meaning:
- fade = presence
- pulse = active awareness
- ripple = listening or detection
- zoom = deeper context
- slide = navigation
- orbit = live world awareness

## What Not to Do
- Do not animate for decoration alone
- Do not overwhelm the screen on launch
- Do not show every feature immediately
- Do not add voice or speech flow in v1

## Success Criterion
If the opening feels like the user is meeting NARI rather than launching software, the animation system is doing its job.
