# Product

## Register

product

## Users
Ankit Upadhyay, a developer and student using Server-01 (Intel i5-2400S, Ubuntu Server) as a private command center. The user is in a high-focus, productive context, often switching between study revision, task execution, and behavioral reflection.

## Product Purpose
NARI (Not A Random Intelligence) is a local-first personal operating system designed to integrate task management, study tracking, notes, and behavioral analytics. It captures a rich "ActivityLog" to serve as the behavioral memory for a future Stage 9 AI layer, while remaining fully functional as an offline-capable, privacy-respecting productivity tool.

## Brand Personality
Precise, Industrial, Technical. 3-word personality: **Sovereign, Precise, Technical.** Emotional goals: Focus, clarity, and the feeling of operating a high-stakes command bridge.

## Anti-references
- **Generic SaaS:** No "Inter" font, no soft purple gradients, no cookie-cutter cards with 32px radii.
- **AI-Slop:** No "empower/supercharge" copy.
- **Consumer Playfulness:** No emojis as icons, no pastel palettes.

## Design Principles
1. **Utility First:** Design serves the workflow. Every element should feel like a piece of equipment, not a decoration.
2. **Data Density:** High information density is a feature, not a bug, provided it is organized with clear hierarchy.
3. **Hardware Honesty:** The UI should reflect the local-first, server-hosted nature. Monospaced type and HUD-like layouts over "mobile-first" consumer minimalism.
4. **AI-Deferred:** Visual affordances should prioritize raw data and logs, treating AI as an upcoming augmentation rather than the primary interface.

## Accessibility & Inclusion
- **Contrast:** Strict 4.5:1 for body text.
- **Reduced Motion:** All "Cyber-Retro" animations (scanlines, glitches) must respect `prefers-reduced-motion`.
- **Keyboard-First:** Full navigation support for the "CLI-adjacent" user.
